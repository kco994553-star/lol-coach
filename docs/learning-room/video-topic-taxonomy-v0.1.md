## 2. 주제 분류: 4×5×4 = 80개 leaf
대분류 / 중분류 / 상세분류. 이는 콘텐츠 확보 건수가 아닌 taxonomy(분류 체계) 초안이다.

### 라인전
- 웨이브 관리: 선푸시·주도권 선택 / 당기기·유지 가능성 / 쌓아서 밀기·속도 조절 / 귀환 전 밀어 넣기
- 견제·딜교환: 상대 막타 순간 접근 / 핵심 스킬 사용 뒤 교환 / 짧은 교환·긴 교환 선택 / 견제 누적과 교전 기회 상실
- 성장·자원 확보: CS 포기·확보 / 경험치 범위·손실 / 레벨 선점·성장 전환 / 체력·마나와 다음 웨이브
- 귀환·복귀·회복: 구매 목적·귀환 결정 / 귀환 전 웨이브 / 복귀·합류 손실 / 조건 붕괴 후 라인 회복
- 정글·지원 정보에 따른 라인 판단: 적 정글 정보·노출 / 아군 지원 가능성 / 큰 웨이브·다이브 / 정글 미확인·stale

### 교전
- 목표·참여 판단: 목표·보호 / 실효 인원 / 싸우지 않을 때 손실 / 참가·대기·교환
- 합류·접근·준비: 도착 순서 / 진입 경로·거리 / 시야·선점 / 퇴로·아군 연결
- 위협·자원 확인: CC·진입기 / HP·마나·기술 / 반격·추가 합류 / 미확인 정보
- 수행·대상 선택: 공격 대상 / 집중과 역할 분담 / 거리·공격 기회 / 아군 보호
- 중단·이탈·재진입: 목표 후 추격 종료 / 악화 시 이탈 / 손실 축소 / 회복 후 재진입

### 운영
- 라인 배치·성장 공간: 사이드 수급 / 미드 합류·분산 / 성장 공간 배분 / 서포터 이탈·복귀
- 정글 동선·자원 배분: 캠프·목적지 / 성장과 갱 비교 / 역갱 대기 비용 / 적 자원 견제·탈출
- 시야·정보·접근: 시야 설치 안전 / 마지막 위치 / 사라진 적 / 시야 제거·공유
- 목표물 준비·템포: 사전 귀환·구매 / 라인과 선이동 / 합류·입구 / 포기·재설정
- 이득 전환·손실 관리: 전투 후 타워·자원 / 반대편 교환 / 앞설 때 현상금 보호 / 뒤질 때 손실 관리

### 한타
- 역할·승리 조건: 팀 목표·내 역할 / 진입·역진입 / 딜러 보호·방해 / 공격 공간 확보
- 핵심 위협 인지: 도달 가능한 위협 / 측면·암살 / 제어기 / 보호 범위
- 배치·지형·거리: 앞뒤 연결 / 측면 접근 / 좁은 길·열린 공간 / 아군 거리·퇴로
- 행동 순서·기술 사용: 시작 조건 / 진입·후속 / 기술 사용·보존 / 사용 후 재배치
- 전투 중 역할 전환: 공격↔보호 / 대상 변경 / 재정렬 / 추격 종료

주분류는 카드가 가르치는 핵심 결정으로 하나만, 관련 분류는 2개 이내 권장. 상황 태그: 역할 TOP/JUNGLE/MID/BOTTOM/SUPPORT, 챔피언/상대/동료/10픽, 레벨, 패치, 웨이브, 정글 정보, 전투 유형. 동일 영상 장면에서 별개 판단이면 복제 영상이 아니라 별개 카드와 같은 source segment 참조.

## 3. 학습 카드 데이터 계약 (설계 후보)
video(video_id,canonical_url,title,channel_id,publication_time,source_patch,language,license_or_access_state)
segment(segment_id,video_id,video_start_ms,video_end_ms,game_clock_ms nullable,transcript_cue_ids,scene_verified,viewer_perspective,source_hash)
lesson(lesson_id,primary_topic_id,secondary_topic_ids,champions,roles,opponents,ally_support,enemy_support,phase,goal,threat,action,reason,required_conditions,stop_or_switch,waiting_cost,alternative_or_recovery,practice_id,claim_ids,segment_ids,review_state)
claim(기존 knowledge registry source/claim 식별자 참조; 중복 승인 저장 금지).
video_start_ms != game_clock_ms. 자막 발언 / 육안으로 검토한 장면 / 앱의 추론은 별도 증거 종류. 관전자 시야와 플레이어의 당시 지식도 별도. 정보 없음은 null/unknown, 영상 결과로 과거의 판단 근거를 소급 생성하지 않는다.

## 4. 수집·검토 상태
LINK_ONLY → TRANSCRIPT_OR_NOTE_AVAILABLE → SPEECH_CANDIDATE → VISUAL_REVIEWED(해당 장면 실제 확인시에만) → CLAIM_REVIEWED(별도 검토 이력) → LESSON_PUBLISHED(적용 범위 명시).
YouTube 링크만으로 자막 원문, 특정 프레임, 패치 또는 전문가 전술이 자동으로 확보된다고 가정하지 않는다. 기존 coach_intake/video.py의 SPEECH_REVIEW_CANDIDATE는 coaching_enabled=false이며 시각 검증과 전술 승인 아님. 기존 coach_v1/expert_bridge.py의 EXPLORATORY 상태 및 AGENTS.md의 USER 결정 보호를 준수. 등록·검색용 게시와 전술 적용은 별도 권한 경계.
