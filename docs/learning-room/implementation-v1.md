## 데이터·화면·API 경계

`coach_v1/learning_room.py` → `scripts/build_learning_room.py` → `web_r4/learning-room.json`. `learning-engine.js`는 같은 공개 색인과 원래 레지스트리를 검색하고 `learning.js`가 화면을 그린다. 전술 판단을 다시 계산하지 않는다. 로컬 `POST /dev/v1/learning/search`는 기존 Bearer 인증·body 제한을 적용한다. 공개 사이트는 정적 파일만 사용하며 PC의 계정·노트·경기 API를 게시하지 않는다.

신규 링크는 `learning.html#learn=...`을 사용한다. 기존 PC 서버의 query 거부·CSP·인증 경계는 유지한다. 원래 게임플랜 URL은 브라우저 세션에 저장하고 공개 링크에는 불투명한 토큰만 넣는다. 저장소 접근을 거부하면 원래 URL을 공개 쿼리에 넣지 않는다. 복기 선택 기록도 동일 세션의 명시적 학습 이동에서만 임시 보존하며 돌아온 자료는 새 조회가 아님을 표시한다.

검색 계약은 NFKC·단어별 AND이며, 원래 주장 참조를 해석한 공개 텍스트를 검색한다. 원본 패치 버전과 패치 검토 상태는 별도 필터다. `DECLARED_UNVERIFIED`나 버전 일치는 현재 패치 전술 검증을 뜻하지 않는다. 영상 시점은 접근·재사용 허용과 유효 구간이 확인된 경우에만 열며, 게임 내부 시점이나 장면 확인을 자동 생성하지 않는다.
