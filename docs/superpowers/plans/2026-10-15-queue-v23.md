# Queue v2.3 Implementation Plan

Goal: PC 경기 전 카드에 출처와 한계가 있는 귀환·저체력 관측을 연결한다.
Architecture: 비공개 원본에서 새 익명 집계를 만들고 기존 pc-coach.v1에 투영한다.
Tech: 기존 Python/Pydantic/SQLite/브라우저 JavaScript 및 trusted GitHub Actions.
Spec: contracts/queue-v23.md, 사용자 2026-10-15 V1–V6.

Global constraints: 기존 완료 증거 재사용/재실행 금지, USER 행 생성 금지,
보호 이슈 쓰기 금지, 모집단·패치 분리, 원본/계정 정보 공개 금지, 게임 중 지시 금지.

1. [x] 통계: recall_stats.py, 새 합성 단위 검사. 사망/취소/누락/패치/표본과
   분모/다른 라인 위치/시간창 검증 → 익명 관측·집계·뷰 계약 제공.
2. [x] 공식 아이템: official_items.py, 버전 보존/실패 fallback/불일치 검사.
   선호4챔피언 분류 후보와 귀환 조언은 원문 근거가 있는 별도 가설 자료로 보존.
3. [x] 수집: 기존 trusted collector에 통계 입력 연결, 기존 private cache 재사용,
   데이터 복구 후 익명 집계만 공개. 갱신 키로 신규 dispatch, 재실행 금지.
4. [x] Main: PC 카드·통계 marker·UNKNOWN 사유·새 신호 연결, 새 통합 검사.
5. [x] 별도 근거 검사와 반론 검사, 마지막 코드 리뷰. 완료된 자료 재검사 금지.
6. [x] 실제 브라우저 신규 흐름·1초 목표 측정, 통과/보류/예시 근거 수준별 수 보고,
   필수 변경 CI와 정상 병합/원격 증거/종료 claim. READY가 남으면 계속.

Review focus: 사망후구매/누락을 정상귀환·0으로 오인, 가설을 공식사실로 표시,
키 교체 뒤 cache 복구 실패 무시, 다른 패치 가격 사용, 게임 시작 후 잔류 카드.

실행 결정: 사용자가 이미 병렬 실행·공통계약 Main 소유·READY 자동 계속을
명시했으므로 추가 승인 없이 기존 단일 Main claim 아래 분리 파일 범위로 진행한다.


실행 결과: 신규 통계·아이템·수집·후보 검토·PC 통합 및 실제 집계 연결 완료.
실제 데이터291 CH/89 PRO경기, 새전술20보류, 기존자동30재사용. 실제자료의
