# Queue v2.1 실행 계획

Goal: 사용자의 전수 승인 부담 없이 근거 수준을 구분한 PC 경기 전 코칭을 제공한다.
Architecture: 기존 immutable USER/계획 저장소를 보존하고 자동 검토 자료·이의·주간 보고를 별도 관리한다.
Tech: Python 표준 라이브러리, 기존 Pydantic/SQLite 로컬 서버, 브라우저 JavaScript, Windows PowerShell.
Spec: contracts/queue-v21.md 및 2026-10-15 사용자 V1–V5 지시.

공통 제약: 보호 결정 이슈 쓰기 금지, 원본 후보/계약 보존, 비밀·계정 정보 노출 금지,
실제 게임 PC 부재는 연결 실증만 외부 차단, 테스트를 코칭 정확도로 표현하지 않는다.

1. [완료] Main: 등급/화면 계약 고정, 원본30 패킷 동결, 별도 근거·반론 검사.
2. [완료] 자료 담당: 최신 전 챔피언 ko_KR 수집·원문 이력·갱신과 실패 검증.
3. [완료] 연결 담당: LCU 투영·인증·단계 차단·수동 전환 합성 검증.
4. [완료] 화면 담당: PC 카드3줄·출처·자동 갱신·이의와 Windows 시작 도구.
5. [완료] Main: 자동 검토 기계 검사·보류 통계·가설 투영·사용자 이의·주간 무작위 보고.
6. [진행] Main: 통합·출처 보존 후속 계약·브라우저 시간 측정·회귀 검증·독립 코드 검토.
7. [진행] Main: 갱신된 Riot 키로 기존 안전 수집 재개·실제 결과 확인·필요 데이터 반영.

Review focus: 등급 위조/누락 검사 통과 방지, 패치·원문 해시·반례 무시 방지,
USER 행 미생성, 이의 즉시 제거, 게임 시작 시 전술 차단, 개인정보 투영 금지,
오래된 비동기 화면 갱신 방지, 실제 브라우저 측정과 PC 외부 차단의 구분.

실제 Windows 설치·게임 클라이언트 연결 실증만 BLOCKED_EXTERNAL. 합성 연결 사례와 실제 브라우저 검증은 완료했으며, API 수집 실행 결과 및 최종 CI는 별도 증거에 기록한다.
