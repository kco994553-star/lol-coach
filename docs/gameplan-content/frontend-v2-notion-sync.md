## 진행률 정정 규칙

산식은 `100 × Σ(main의 행별 0/0.5/1) / 160`의 동일 가중 기능 수 **추정치**다. `1`은 해당 행의 전체 인수/연결이 main에서 확인된 경우, `0.5`는 일부가 main에서 확인되고 부족 기능이 명시된 경우다. 미지원 표시만 구현한 기능은0, 미병합 로컬 신규 구현도0이다. 동일 행을 기본/상대/모바일 화면 수로 여러 번 세지 않는다.

관리자·상세·그래프가 다른 숫자를 갖거나 수치와 ‘미산정’이 함께 남으면 이전 수치의 시각/범위/분모를 역사로 보존한다. 최신 main 근거로 산출한 새 평가표를 붙이고 세 페이지를 같은 값으로 맞춘다. 실제 재조회 전에는 ‘모순 해소 완료’라고 기록하지 않는다.
