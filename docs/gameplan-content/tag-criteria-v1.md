# 게임플랜 태그와 지원 범위 v1

2026-10-24 사용자 지시: 짧은 태그의 종류와 적용 기준을 정하고 계속 구현한다.

태그는 최종 delivery(화면 전달 결과)의 행동에서만 가져온다. 보라색 행동/조건, 주황색 주의, 회색 자료 상태를 구분한다. 기본 2개를 목표로 하되 최대 3개이며, 근거 없는 태그로 개수를 채우지 않는다. 각 태그는 종류·식별자·원문 경로를 가진다. 카드 선택은 해당 단계 상세로 연결된다.

이번 구현은 제한된 기존 표현을 짧게 줄이는 매핑이다. 의미를 자유롭게 추론하는 분류기나 새로운 전술 선택 엔진이 아니다. 인식하지 못한 표현은 '세부 행동 확인'으로 표시한다. 부정·금지·미확인 표현을 긍정 행동으로 줄이지 않도록 보수적으로 제외한다. 중단 상태가 최종 행동에 반영된 경우 이전 압박/교환 태그를 유지하지 않는다. 모든 후보 태그의 적용 규칙을 완성한 것은 아니다.

| 단계 | 행동 예 | 근거 위치 |
|---|---|---|
| 라인전 | 견제 후 압박, 수급 지키기, 추격 중단 | 최종 목적 및 교환 행동, 명시적인 교전 상태 변경 |
| 초반 정글 | 성장·지원 연결 | 최종 초반 목적 |
| 운영 | 사이드 압박, 미드 압박, 시야 선점, 본대 이득 연결 | 최종 우선 이득 |
| 한타 | 앞라인 공격, 진입 후 받아치기, 공격 틈에 전진, 제어 후 후속 공격 | 최종 공격 시작 조건 |

## 지원 범위

- CONDITIONAL_PLAN(조건부 계획): 개별 설명 경로 또는 전용 내용 규칙의 근거 연결이 있다. 상성 우세·실제 상태·전술 정확도 인증이 아니다.
- BASELINE_ONLY(기본 방향만 제공): 해당 챔피언 기본 방향은 있으나 조합별 연계가 연결되지 않았다. 전술 태그를 꾸며 넣지 않는다.
- GENERAL_ONLY(개별 계획 자료 부족): 공통 원칙만 제공한다. 행동 태그 대신 자료 상태를 표시하고 본문 위에도 안내한다.
- SOURCE_REVIEW_REQUIRED(자료 재확인 필요): 적용 가능한 출처 범위 확인이 필요하다.

지원 범위는 최종 전달 결과에 포함하며 화면에서 다시 챔피언/포지션으로 추정하지 않는다. 일반 행동과 본문은 보존하고 그 범위를 명확하게 표시한다. 따라서 이 수정은 무작위 조합의 내용 자체를 보강하거나 반복 문장을 다양하게 바꾼 것이 아니다.

## 완료 범위와 남은 작업

첫 범위는 같은 최종 행동에서 태그/자료 상태를 생성하고 화면에 표시하는 것이다. 선언형 전술 식별자에서 태그를 직접 고르는 전체 규칙 전환, 모든 후보 태그, 단계별 독립된 전술 근거 등록과 지원 범위 계산은 남아 있다. 기존 기본 방향 4명과 별도 조건부 규칙을 전체 챔피언 지원으로 계산하지 않는다.

재발 검사: 일반 계획의 행동 태그 금지, 기본 자료/조합 연계 구분, 역할 필드만 바꿔도 이미 만든 전달 결과는 불변, 기회를 놓친 가정에서 추격 중단, 부정 문구의 긍정 태그 금지, PC/모바일에서 자료 부족 표시 확인.
