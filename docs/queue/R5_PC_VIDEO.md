# 게임 PC·영상 준비 — R5

상태: **BLOCKED_EXTERNAL**. 준비 안내만 완료했으며 실제 PC 원본·본인 영상은 아직 없습니다. Riot 경기 기록 복기(`/postgame`)는 이 자료 없이 먼저 사용할 수 있습니다.

## 게임 PC에서 한 번 실행

1. Windows 게임 PC에 저장소를 내려받고 Python 3.11 이상을 설치합니다. LoL을 실행한 PC에서 진행하세요.
2. 연습/사용자 설정 경기에서 `collect_windows.cmd`를 한 번 더블클릭합니다. 관리자 실행이나 Riot API 키 입력은 필요 없습니다. 게임 조작·반복 수집은 하지 않습니다.
3. 창에 표시된 `private/capture-날짜/`를 보존합니다. `status.json`의 `passed=true`, `stage=DONE`은 수집 성공입니다. 실패 파일도 덮어쓰지 마세요.
4. 폴더의 `raw.json`, `receipt.json`, `audit.json`, `status.json`, `riotgames.pem`을 함께 보존합니다. 원본에는 이름 등 개인정보가 있으므로 Git·공개 링크에 올리지 않습니다.
5. 수동 메모에 포지션·챔피언·패치·게임 모드·관측 시점을 적습니다. 모르면 미확인으로 남깁니다. 자세한 양식은 [Q10 준비](Q10_GAME_PC_CAPTURE.md)에 있습니다.

## 녹화 권장값

OBS의 **게임 캡처**로 LoL 게임 창을 녹화합니다. 권장값은 1920×1080, 30fps(여유 있으면60fps), MKV, 하드웨어 H.264, 품질 CQP20–23입니다. 이는 분석 필수 기준이 아니라 저장 공간·읽기 쉬움의 권장값입니다. 필요하면 OBS에서 MP4로 재다중화합니다.

화면 상단의 **게임 시계**, 내 레벨·아이템 HUD가 보이도록 합니다. HUD를 자르거나 시계를 덮는 오버레이를 쓰지 않습니다. 미니맵은 보존하되 첫 분석은 **게임 시계 읽기**와 타임라인 정렬입니다. 미니맵 추적은 후순위입니다. 내 시점인지, 재생 영상인지 별도 메모합니다.

게임 시작부터 종료까지 녹화하는 것이 좋습니다. 파일이 크면 개인 폴더에 원본을 보존하고, 관심 구간을 **10분 이하**로 잘라 따로 준비하세요. 파일명에 Riot ID를 넣을 필요는 없습니다.

## 앱에 넣기

- Riot 기록: `/postgame`에서 Match-V5 경기·타임라인 JSON과 내 participantId를 가져옵니다. 두 원본은 로컬 비공개 경로에만 저장됩니다. 새 수집 CLI는 R3 안내를 따릅니다.
- PC 원본: 기존 자료 화면 `/`의 원본 수집 가져오기에서 기존 `lol-coach-raw-capture-v1` **봉투 JSON**을 선택합니다. `collect_windows.cmd`의 **plain raw.json은 봉투가 아니므로 직접 넣지 않습니다**. 해당 수집 폴더는 위 Q10 원본 진단 절차로 보존하고 전달합니다.
- 영상: `/`의 영상/타임스탬프 자료 경로 또는 `/experts`의 수동 발언 후보 가져오기를 사용합니다. 영상 원본 자동 업로드/게임 시계 OCR은 아직 제공되지 않습니다. Gemini 앱에서 만든 짧은 타임스탬프 요약은 `/experts`에서 EXPLORATORY 후보로 저장할 수 있습니다.

## 영상–타임라인 기준점

별도 개인 메모에 `영상 파일 시각 → 화면 게임 시각`을 적습니다(예: 영상02:13 → 게임01:00). 처음·중간·끝에서 각각 실제 화면으로 확인한 기준점을 남기고 정지/편집/누락 구간을 표시합니다. 매치 타임라인의 분 단위 표본은 프레임 사이 상태를 알 수 없습니다. 시계 읽기 자동 분석 전까지 정렬 오차는 미산정입니다. 숨은 상대·웨이브·스킬 준비 상태를 기록만으로 추정하지 않습니다.

로컬 앱의 전체 시작 명령과 화면 주소는 [v2.0 로컬 사용](V20_LOCAL_USE.md)을 참조하세요. native Windows 개인 폴더는 본인 계정만 접근하도록 NTFS 권한을 설정해야 합니다. 앱 chmod는 NTFS ACL 보호를 검증하지 않습니다. WSL에서는 POSIX0700/0600 검사를 적용합니다.
