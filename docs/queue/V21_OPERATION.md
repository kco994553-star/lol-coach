# Queue v2.1 운영 결과

사용자에게 후보 전수 승인·자료 수집·출처 대조를 요구하지 않는다.
PC 로컬 앱의 기본 주소는 `/pc`, Windows 시작 파일은 `Start-LoL-Coach.cmd`다.
기존 PC 편집·백업·USER 결정과 보호 결정 이슈는 보존한다. 새 이슈나 모바일 응답 제품을 만들지 않는다.

## 자동 검토

원본 350개와 실전 원본 30개를 그대로 보존했다. 새 `auto-advice.v1` 계보는 원본 ID·명세
해시를 연결하고 경기 전의 수동 조건을 자동 관측 필드와 구분한다.
Main 작성과 별개인 근거 담당·반론 담당이 원문/반례를 검사했다.
같은 모델의 표결이 아니라 서로 다른 역할의 필수 검사이며, 기계 검사가 하나라도 실패하면 보류한다.
실행 패킷·검토 영수증·원문을 해시로 연결하고 바뀐 자료나 임의 PASS 선언을 재사용하지 않는다.

첫 검사에서는 30개 모두 점검 항목의 의미 불일치로 보류됐고, 그중 유나라 한 항목에
인용 밖 원인·용어가 있었다. 첫 패킷과 실패 영수증은 `history/initial`에 보존했다.
수정 후 두 역할이 30개를 다시 개별 검사하여 모두 통과했다. USER 승인 생성은 0이다.
현재 Q15는 골드·경험치·미니언 처치 관측 자료이며, 이 30개에는 통계 수치 주장이 없어
통계 일치 검사는 해당 없음으로 기록했다. 교전 승률이나 조언 효과를 통계로 입증했다고 주장하지 않는다.

보류된 내용도 원문을 확인하고 현재 픽·패치 조건이 맞으면 AI 작성 가설로 구분한다.
출처가 없거나 해시가 다르면 표시하지 않는다. 실제 기술 상태는 추적하지 않는다.
사용자 이의는 별도 로컬 이력으로 남기고 즉시 모든 카드와 현재 주간 보고 투영에서 제외한다.
주간 보고는 앱이 실행 중일 때 무작위 최대 다섯 개를 로컬에 보존하며 화면에서 선택적으로 펼친다.
앱이 꺼진 동안의 새 주차 보고는 다음 실행 때 생성한다. 외부 메시지나 이슈 댓글을 보내지 않는다.

## 공식 설명과 연결

공식 버전 조회 결과 `16.20.1`, 한국어 전 챔피언 173명·기술 865개를 확보했다.
패치 16.20의 자료이며 실제 입력 패치 미확인/불일치는 화면에 구분한다.
매일 새 공식 버전을 확인하고 버전별 원문·URL·해시를 보존한다.
자료 갱신과 픽창 감시는 서로 다른 작업에서 실행해 갱신 중에도 게임 시작을 감시한다.

로컬 연결은 선택·확정·포지션·밴·단계만 투영한다. 계정 식별 필드를 요청/저장/표시하지 않는다.
공개 형식 자료와 합성 입력을 검증했으며 실제 Windows 설치·바로가기·게임 PC 연결 실증은
현재 환경에서 외부 차단이다. 실제 클라이언트 패치를 공식 자료의 최신 버전으로 추정하지 않는다.
연결 실패·형식 변경·오래된 응답은 이전 카드를 내리고 수동으로 전환한다.
게임 시작 또는 자동 단계 미확인에는 경기 전 전술을 노출하지 않는다.

## 예시 카드 집계

`python scripts/report_queue_v21.py`로 승인·저장 입력을 만들지 않고 오프라인 재현한다.
Golden10에서 내 포지션을 원딜/케이틀린으로 둔 새 PC 화면은 25개 카드다:
공식 사실 10, 통계 1, 자동 검토 14, 사용자 승인 0, 미검토 가설 0.
첫 화면에는 관련 조언 세 개와 내 공식 설명을 먼저 보여 주고 나머지는 펼친다.
포지션별 수와 전체 집계는 `evidence/queue/v21/report.json`에 있다.
기존 결론형 45칸은 USER 승인 전용으로 계속 0/45다. 참고·조건부 카드 수를
라인 승패나 확정 결론으로 바꿔 세지 않는다.

브라우저 시간은 합성 픽 입력부터 실제 로컬 서버 계산·Chromium 표시까지 측정한다.
실제 Windows와 게임 클라이언트의 지연이나 코칭 정확도를 측정한 수치는 아니다.

## 보존과 검증

원본 USER SQLite·엔진·기존 저장 계획과 동결 계약은 변경하지 않았다.
자동 검토 이의·주간 보고는 별도 `.auto.sqlite`다. 기존 입력/계획 내보내기에는
이 새 파일이 포함되지 않으므로 PC 데이터를 옮길 때 앱을 종료한 뒤 로컬 개인 데이터 폴더를 함께 보존한다.
새 검증기는 이전 출처 검사 자체를 바꾸지 않고 보관한 정확한 선행 파일에 다시 실행하며,
새 파일 해시와 AUTO/USER 분리를 별도 후속 계약으로 검사한다.
