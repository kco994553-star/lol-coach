# PC 귀환·저체력 계획 사용

Windows에서 `Start-LoL-Coach.cmd`를 실행하면 기존 설치·실행·바로가기·접속키
연결을 사용한다. PC에서 롤 클라이언트가 없으면 자동으로 수동 입력을 사용한다.
이 연결은 공식 지원 API가 아니며 실제 Windows 픽창 연결은 아직 외부 실증 대기다.

`/pc`에서 챔피언·포지션·경기 전 단계·패치를 입력한다. 추가 자료가 들어오면
내 챔피언→맞라이너→정글→조합 순서로 카드가 늘어난다. 다른 준비 조언 목록에서
첫 귀환과 저체력 관측을 펼쳐 원문·버전·해시·표본을 확인한다.

첫 귀환은 구매 시각으로 추정한다. 시작 구매·사망 뒤 구매·취소한 구매를 분리한다.
직전 프레임 골드는 구매 순간 골드가 아니다. 최빈 구매 묶음의 공식 기본 가격
합계는 참고값이며, 보유 부품·할인을 몰라 지금 필요한 골드를 정확히 알 수는 없다.
패치가 다른 아이템 가격으로 목표를 만들지 않는다.

챔피언별 유효 5경기 미만이면 같은 패치·포지션 전체로 보충하고, 그마저 없으면
미확인이다. 모집단·다른 패치를 합치지 않는다. 5경기는 최소 출력 규칙이며
통계적으로 충분하다는 뜻이 아니다. Q15 그래프의 선은 관측 자원 차이이며,
귀환 구매 중앙값 세로선은 강한 시점이나 개인 예측이 아니다.

저체력은 분 단위 수신 시점 체력 30% 이하, 결과 창은 이후 120초로 정의했다.
20%·40% 및 60·180초 집계도 함께 보존한다. 이 경계는 분석 규칙이며 게임 중
행동 권장이 아니다. 구매한 경우와 다음 프레임에 라인 잔류가 관측된 경우의
사망·상대 다른 라인 킬 관여·방패·정글 오브젝트를 비교한다. 관측이 빠지면
0으로 바꾸지 않는다. 같은 사건이 여러 참가자의 시간창에 포함될 수 있으며
경기별 평균을 먼저 계산한다. 웨이브·실제 귀환 시작·상대 의도는 미확인이다.

새 분류·귀환 조언은 7개 필드와 원문을 갖춘 별도 후보다. 출처가 기술 기전만
말할 때 빠름/높음/안전함·최적 행동을 확정하지 않는다. 보류된 내용은 미검토
가설로 표시하며 USER 승인 행을 만들지 않는다. 기존 자동 검토 30개의 사용자
이의·주간 최대 5개 무작위 보고는 그대로 유지한다. 새 보류 후보는 자동 검토
통과 수에 합치지 않는다. 게임이 시작되면 경기 전 전술·귀환 카드는 숨긴다.

실제 데이터는 trusted main의 `Recall and low-health anonymous reference collection`
작업으로 수집한다. 기본은 기존 비공개 암호화 프로 원본을 오프라인 재사용하며,
`collect_challenger=true`일 때만 갱신 키로 제한된 신규 수집을 한다. 최초 인증
실패에서 멈추며 쿨타임·요청 한도·개인정보 경계를 유지한다. 공개 익명 자료만
`data/recall/YYYY-MM-DD/{pro,challenger}/`에 보존한다. 예전 익명 자원 곡선에
없던 체력·구매 정보를 추측해 채우지 않는다.

이번 검증은 신규 변경만 실행한다. 완료된 v2.1 검사 결과는 정확한 소스·커밋·
해시와 함께 재사용하며, 기존 동결 계약과 사용자 결정은 보존한다. 합성 사례와
브라우저 검사는 구현 검증이지 코칭 정확도 검증이 아니다.
