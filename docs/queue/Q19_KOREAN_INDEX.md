# Q19 한국어 자막 주제 색인

근거: 사용자 대기열 v1.6(2026-10-11)의 Q19 한국어 주제어 추가. 기준 커밋은 `9657177`이다. `coach_intake/video.py`는 `FREEZE_MANIFEST.json`의 보호 payload에 포함되지 않으며, 해당 작업 공간에서 AGENTS.md는 발견되지 않았다. Frozen 문서·기존 영어 테스트·원문 자료는 수정하지 않았다.

기존 `index_transcript(raw, video_id)`는 시간표시 자막을 읽어 영어 단어가 나타난 cue를 주제별 조사 후보로 반환한다. 확장은 같은 함수와 `lol-coach-video-index-v1` 출력 필드를 유지하면서 한국어 검색 별칭을 추가한다. 새로운 영어 검색어는 추가하지 않는다.

| 주제 키 | 한국어 별칭 | 기존 영어 별칭 |
| --- | --- | --- |
| WAVE | 웨이브, 미니언 | wave, minion, cs |
| ROAM | 로밍 | roam, roaming, roams |
| JUNGLE | 정글, 갱, 갱킹 | jungle, jungler, gank, ganked |
| VISION | 시야, 와드 | vision, ward, wards |
| TRADE | 딜교, 딜교환 | trade, trades, trading |
| LANE | 라인 | 없음 |
| TEAMFIGHT | 한타 | 없음 |
| MACRO | 운영 | 없음 |
| SIDE | 사이드 | 없음 |
| MAIN_BODY | 본대 | 없음 |
| OBJECTIVE | 오브젝트 | 없음 |

주제 순서는 기존 다섯 키를 먼저 유지하고 LANE, TEAMFIGHT, MACRO, SIDE, MAIN_BODY, OBJECTIVE를 뒤에 추가한다. 한 cue에서 영어·한국어가 같은 주제를 가리켜도 키는 한 번만 반환한다. cue 순서·원래 cue 번호·영상 시각은 그대로 유지한다.

한국어 검색은 발화의 검색용 사본에만 NFC 정규화를 적용하고, 연속된 완성형 한글 음절을 단어로 분리한다. 별칭 전체 또는 별칭 뒤에 아래 조사 한 개가 붙은 단어만 일치한다. 임의 부분 문자열, 형태소 추정, 띄어쓰기 복구 또는 의미 해석은 하지 않는다.

`은, 는, 이, 가, 을, 를, 의, 에, 에서, 에게, 로, 으로, 와, 과, 도, 만, 부터, 까지, 보다, 처럼, 마다, 랑, 이랑, 이나, 나, 라도, 이라도, 은요, 는요, 요, 들`

예: `웨이브를`, `라인에서`, `갱킹으로`, `딜교환을`은 검색된다. `라인업`, `갱년기`, `운영체제`, `사이드바`는 검색되지 않는다. 목록 밖 활용·복합어와 오인식 자막은 놓칠 수 있다. 중국어 별칭·번역 추정은 추가하지 않는다. 언어 헤더는 입력값을 그대로 보존하며 혼합 언어 cue에서도 동일한 명시적 별칭만 검색한다.

원문 `raw` 바이트는 변경하지 않고 기존 SHA-256 계산에 그대로 사용한다. 색인에는 발화 원문을 저장하지 않는다. `game_time_ms=null`, `visual_verified=false`, `decision_eligible=false`, `coaching_enabled=false`와 기존 출처·시야·패치 미확인 필드를 유지한다. `한타는 하지 않는다` 같은 부정문도 한타라는 주제의 조사 후보일 뿐이며, 행동 권고나 전문가 주장의 참·거짓을 판정하지 않는다.

검증용 문장은 작업자가 만든 짧은 합성 문자열이다. 실제 영상·자막 원문, 전문가 발언, 개인정보 또는 자동 수집 자료를 추가하지 않았다. 새 테스트는 요청된 13개 표현의 매핑, 조사·부분 문자열 경계, 기존 영어 단어 동작, 혼합 언어 중복 제거, Unicode 정규화 후 원문 해시 보존, 후보 필드와 부정문·중국어 경계를 검사한다.

검증: 기존 R5 19개 테스트가 변경 전에 통과했고, 새 한국어 테스트 5개는 구현 전 실패 후 통과했다. 한국어·기존 영상 테스트 10개와 전체 R5 24개가 통과했다. 이 수는 검색 코드의 합성 검사 결과이며 실제 전문가 지식·코칭 정확도 검증이 아니다. Q19의 전문가 후보 승인·API 자동화·통계 대조는 Main의 별도 작업이다.

추가 회귀 검증: `python -m unittest discover -q` 전체 448개 통과(기존 외부 원본 의존 검사 1개 skip), `compileall` 및 `git diff --check` 통과. 기존 보호 검증 파일·원문·실행 이력은 수정하지 않았다.
