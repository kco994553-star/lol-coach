# Q18 conditional movement — queue v1.4

Authority and frozen interface: `contracts/pregame-v3.md` at `c038bfb`. Implementation is additive: `coach_v1/movement.py` consumes evaluator traces and does not alter V1/V2 serialization, approvals, stores, servers, or the frozen core.

`build_movement_plan(traces, draft, statistics=None, test_mode=False)` returns the existing MOVEMENT Cell shape. Each copied trace contains one stage row in `output.movement`. A supported row retains the original conditional role, why, exceptions, source and patch, plus `movement_statistics` with the immutable dataset digest, cohort identifier, source metadata and points. Missing support stays UNKNOWN and remains visible in `rules`; a cell with some supported rows is KNOWN with the other rows' missing-support reasons. The text is conditional PRE_GAME planning, not a detection of the current phase.

A row needs an applied, reviewed evaluator trace, exact draft patch, a matching hashed nonsynthetic source, and a statistics reference bound to the canonical dataset digest. The cohort must match the actual subject champion, position, patch, source tier, stage and exact condition signature, with at least one precision-eligible point. Dataset provider and sample kind must agree: RIOT_API with REAL, SYNTHETIC with SYNTHETIC. Champion names must use canonical alphanumeric champion identifiers. Synthetic sources and data are accepted only with internal `test_mode=True`. Minute-only cohorts cannot support stage plans. Current official kit archives do not substantiate movement tactics; no real movement coaching has been approved or generated by this implementation.

Layers are ordered DEFAULT → TYPE → CHAMPION → COMPOSITION. That ordering alone does not choose a plan. Replacement requires an explicit reviewed higher-layer `overrides` link to the lower rule, with identical stage, subject, position and conditions. Replaced rows remain in the audit as OVERRIDDEN. Contradictory remaining rows retain CONFLICTING status and both original traces. Existing upstream conflicts remain conflicts when statistical support is otherwise valid.

`build_movement_dataset(pairs, source=..., phase_annotations=None)` accepts private ephemeral Match-V5 match/timeline pairs. It verifies matching match identity, KR/map11/ranked420/classic, exact patch and window, canonical complete team roles and chronological received frames. The timeline must declare a 60,000 ms frame interval. Frames are binned by floor(elapsed timestamp / 60,000); each match bin uses its latest received frame. All five same-team coordinates are required at that frame. Bin labels introduce less than one minute of quantization and do not interpolate movement. Actual received timestamps remain the annotation keys. The center is the coordinate-wise median, including the subject; each subject distance is Euclidean. This is a **known-allies median proxy**, not an observed team formation or main body, travel time, ability to join, or recommendation to split/group.

Each match contributes one observation per champion/position/minute/cohort. Same-champion same-role observations from both teams are averaged within the match. Match hashes deduplicate input; tier is the collection's current league seed cohort rather than all participants' historical ranks. Output contains only aggregate means, median, quartiles, Student-t 95% mean intervals, sample counts and safe lineage; raw match IDs, participants, identities and coordinates are never persisted.

Precision follows Q15's public `student_t_critical(df)`: `n >= 2` and full confidence interval width no greater than empirical sample SD. This is an operational display policy, not validated tactical accuracy. Zero variance is permitted with an explicit limitation; sparse or wide intervals are hidden and cannot support rules. Q15's public helper is a runtime dependency.

Without annotations, every cohort has `stage=null` and `condition_signature=null`, including late minute labels. Optional private annotations are a list of `{match_sha256, timestamp_ms, stage, stage_conditions, source_sha256, source_pointer, verification}`. VERIFIED annotations need exact sample time and source SHA; EARLY needs explicit laning, MID an explicit first-turret or major-objective transition, and LATE explicit long-respawn risk. MANUAL_UNVERIFIED annotations remain descriptive and do not create stage cohorts. Contradictory duplicate annotations are rejected. Persisted lineage contains only `{sha256, pointer, verification}` in `source.phase_annotation_sources`. The caller supplies VERIFIED evidence validation; this module does not confer approval.

`validate_movement_dataset(dataset)` enforces the aggregate allowlist, formula and precision policy, hash/cohort identity, counts, stage conditions and lineage, finite values and eligibility consistency. It returns an independent copy. Approval-bound rule references protect the dataset content against subsequent changes; the digest alone is not evidence of tactical correctness.

Verification uses synthetic contract mechanics only. Tests cover median arithmetic, no phase from minutes, missing coordinates, deduplication and correlated teammates, annotation provenance, insufficient intervals, source/hash/patch/subject binding, synthetic isolation, partial UNKNOWN rows, explicit overrides, upstream conflicts, immutable inputs and strict aggregate validation. No personal-match coaching accuracy is measured: `coaching_accuracy=null`. Actual-versus-plan review still depends on Q11/Q13 samples and video and remains blocked.

Review amendment: `source.time_bin_policy` is exactly `{kind: "ELAPSED_MINUTE_FLOOR", frame_interval_ms: 60000, selection: "LATEST_RECEIVED_FRAME_PER_MATCH_BIN"}`. This policy is validated and included in the dataset digest. Regression tests use jittered 300153/360211/420399 ms frames from three matches, duplicate-bin representatives, exact annotation timestamps, unsupported frame intervals, and contradictory provider/sample-kind metadata.

The aggregate validator also requires provider/sample-kind parity, canonical alphanumeric champion names, the standard tier whitelist, numeric major.minor patch identifiers, and confidence intervals centered on the mean. These gates prevent contradictory source metadata and malformed intervals from becoming sufficient support.

Duration boundary: the full raw frame sequence must first have finite, nonnegative, strictly increasing timestamps. Frames after the reported game duration are then excluded individually before bin selection and phase matching; earlier valid frames survive. Exclusion adds `FRAME_AFTER_REPORTED_END_EXCLUDED_DURATION_RESOLUTION_UNKNOWN`. No rounding allowance or game-end extension is inferred. A two-match regression retains the 60,000 ms cohort while excluding 300,153 ms frames and their late-phase evidence from a reported 300-second game.
