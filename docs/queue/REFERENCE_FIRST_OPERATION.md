# 공식 사실 우선 운영 — 2026-10-14

사용자가 "앞으로 모두 내가 다해야 하는 것인가"라고 지적했고, 확인된 공식 사실을 출처와 함께 바로 제공하고 해석이 갈리는 전술만 소수로 검토받는 방향으로 바꾸라고 지시했다. 이 결정이 이전의 모든 조언 사용자 승인 대기 운영을 대체한다.

공식 한국어 Data Dragon 설명을 직접 수집해 표시한다. 예시 조합과 선호 챔피언의 합집합 13명에 대해 기본 지속 효과와 기본 기술 4개, 총 65개 설명을 확보했다. 승인 없이 참고할 수 있으며 URL·자료 버전·원본 해시·자료 항목을 보존한다. 기술 설명을 전술 우열·승패·최적 플레이 주장으로 바꾸지 않는다. 한국어 원문에서 표시용 태그와 공백만 정리한다. 근거 수집·출처 확인·패치 구분·정리는 Codex가 맡는다.

자료 버전은 16.20.1, 해당 보관 자료의 경기 버전 계열은 16.20이다. 실제 입력의 패치를 채워 넣지 않는다. 입력 패치가 없으면 현재 적용 여부 미확인, 다르면 보관 자료임을 화면에서 밝힌다. 원본이 없거나 해시·형식이 맞지 않으면 확인된 설명으로 표시하지 않는다. 현재 지원되지 않는 챔피언의 설명을 만들어 채우지 않는다.

`/review-queue`는 먼저 공식 사실을 보여 주고, 저장한 최근 픽·상대와 관련된 전술을 기본 최대 5개로 추린다. 선택한 챔피언·포지션·상대·패치 조건을 따르며 같은 챔피언의 같은 카드 종류를 중복 선정하지 않는다. 저장된 픽이 없으면 케이틀린 예시임을 명시한다. 검토는 선택사항이다. 나머지는 "보관된 모든 전술 보기"로 접근할 수 있고 전수 처리할 할 일로 표시하지 않는다. 기존 원본 350개와 실전 후보 30개의 내용은 변경하지 않았다.

경기 전 계획을 생성하면 입력한 조합의 공식 설명이 자동으로 표시된다. 지식 승인 0개여도 설명을 볼 수 있다. 9개 계획 카드와 기존 사용자 결정 관문은 별도로 유지하므로 참고 자료 수를 승인 수·전술 카드 채움 수로 바꾸지 않는다. 공식 사실 확인 때문에 USER 결정 행을 쓰거나 승인된 전술을 만들어내지 않는다.

이전 이슈 #30–#32는 선택적 수정·의견 채널이다. 사용자가 전부 읽고 승인할 필요는 없다. Codex는 그 결정 이슈와 댓글을 작성·수정하지 않는다. 새 모바일 검토 묶음은 사용자가 요청했을 때 관련 쟁점만 게시하며 일괄 검토를 반복하지 않는다.

API는 기존 인증을 사용한다. `GET /dev/v1/pregame/official-facts`는 전체 보관 설명, `POST`는 `{champions,patch}`에 맞는 설명을 읽기만 한다. 일반 검토 경로는 최대 5개, `/review-queue/archive`와 `/archive/page`는 기존 전체 검토 투영을 보존한다. 원격 원문은 `scripts/collect_official_reference.py`로 받아 로컬에서 검증한다. 화면 조회 중 외부 API를 호출하거나 새 키를 요구하지 않는다.

기존 사용자 결정·SQL·동결 27개 계약·과거 버전 계약·후보 파일은 보존한다. 바뀐 화면·검토 운영만 새 버전 계약과 직전 코드 보관본으로 연결한다. 새 자동 사실 확인의 의미는 공식 원문과 보관 파일을 확인했다는 것이며, 전문가 검토·실제 경기 코칭 정확도를 증명하지 않는다.
