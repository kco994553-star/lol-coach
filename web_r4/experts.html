출처가 연결된 발언 후보

같은 영상의 여러 요약은 같은 출처 그룹입니다. 영상 수와 발언자 확인 표기를 따로 세며, 인과적 독립성이나 의미의 동일성을 확정하지 않습니다.

선택한 저장 버전 · 직접 검토

내용·출처·반례·한계는 아래 저장 버전에 고정됩니다. 패치와 적용 범위를 직접 채우고, 영상 문맥을 확인한 뒤 결정하세요. 출판·업로드 날짜가 게임 패치를 뜻하지 않습니다.

발언 승인과 수치 비교는 별개입니다. 실행에는 별도의 명시적 명세와 검토가 필요합니다.
