# 사용자 지식 결정의 보호 규칙

- `[지식 검토]`로 시작하는 제목의 이슈 및 `config/practical_review_issues.json`에 등록한 결정 이슈는 **사용자 결정 전용**이다.
- Codex와 모든 하위 에이전트는 이 이슈에 댓글을 작성하거나 이슈·댓글을 수정·삭제·닫기·재열기·반응 추가할 수 없다. 같은 GitHub 계정이므로 작성자 로그인만으로 사람과 Codex를 구분할 수 없으며 이 규칙으로 보장한다.
- 사용자가 명시적으로 요청한 새 검토 이슈 생성만 허용한다. 생성 후 본문·제목도 수정하지 않는다. 수정 후보는 PC 검토 큐에서 새 버전으로 다룬다.
- 결정 가져오기는 등록 이슈의 댓글 **조회**와 로컬 저장만 수행한다. 가져온 댓글 URL·작성 시각·편집 시각·원문·해시·작성자를 보존한다. 실패한 댓글을 승인으로 대체하지 않는다.
- GitHub와 PC는 모두 USER 결정이다. 테스트 결정은 격리된 가상 자료에만 생성하고 실제 사용자 승인 수에 합치지 않는다. 사용자 댓글이 없으면 실제 승인은 0이다.
- 기존 350개 후보 파일과 동결 계약은 보존한다. 재작성 후보는 별도 계보로 관리한다. 수정 요청은 EXPLORATORY 새 버전이며 자동 승인이 아니다.

# 공식 사실 우선 운영 — 사용자 방향 변경

- 공식 한국어 원문과 자료의 버전·URL·해시를 확인한 설명은 승인 없이 참고 정보로 제공한다. 사실 제공을 USER 승인 또는 전술 검증으로 기록하지 않는다.
- 사용자에게 350개 또는 30개 전체 검토를 요구하지 않는다. 저장한 픽과 관련된 해석이 필요한 전술만 기본 최대 5개로 추리며 검토는 선택사항이다. 나머지는 보관한다.
- 자료 수집·출처 확인·패치 구분·후보 정리·결정 반영은 Codex가 담당한다. 사용자에게 근거 수집이나 전수 검증을 넘기지 않는다.
- 기존 결정 이슈는 선택적 의견 채널로 보존한다. Codex의 댓글 작성·수정 금지는 계속 적용한다. 자동 사실 확인은 사용자 승인 이력을 대신하거나 승격시키지 않는다.
