# 독립 검토 및 확인

별도 읽기 전용 검토자가 원문 버전과 game_patch 매핑 미검증, 자료 목록 손상 시 검토 큐 전체 중단을 지적했다. 두 문제를 새 검사로 재현한 뒤 목록 형식·패치 계열·언어·중복을 검증하고 자료 미확인으로 반환하도록 수정했다. 읽기 전용 재검토에서 두 지적 해결, 추가 중요 문제 없음 및 새 기능 검사 13개 통과를 확인했다. 실제 사용자 승인이나 전술 검증으로 집계하지 않는다.

전체 경기 전 검사 371개, 기존 MVP 검사 193개 통과. 새 브라우저는 승인 없이 공식 설명을 보고 실제 API로 연결하며 8개 검사를 통과했다. 기존 30개 조언 보관·화면 검사 8개와 기존 검토 큐 20개 검사도 통과했다.

기존 PC 검사에서 새 운영에 해당하지 않는 안내와 보관 제어가 통계 표를 첫 화면 아래로 밀었다. 측정값은 표 아래쪽 894.55px/화면844px였고 해당 영역을 제거한 단일 진단에서823.77px로 돌아왔다. 그 제어를 새 운영 대상에만 표시하도록 고쳤으며 원래 검사 기대값을 바꾸지 않고 통과했다. 최초 실패와 진단을 ../v20/의 실행 영수증에 보존했다.

공식 설명 65개는 참고 자료이며 승인된 지식 또는 45개 예시 전술 카드의 채움 수가 아니다. 현재 승인0·전술 카드0/45와 구분한다. 원본 350개 및 기존 실전 후보 30개 파일·동결 자료 바이트를 보존했다.

추가 보존 검사 실행은 기능 검사 실패 없이, 실행 중 새 증거 문서 5개를 저장한 변경을 감지해 FAIL이었다. 증거 작성을 끝낸 뒤 동일 검사를 다시 실행한다. 해당 실패 출력과 변경 목록을 보존했으며 관문을 완화하지 않았다.

증거 기록을 마친 뒤 동일 전체 MVP 보존 검사를 재실행해 PASS를 확인했다. 기능 검사 실패0·실행 중 소스 변경0·보관 증거 변경0이다. 결과는 mvp-verifier-stable.json/log에 보존한다.
