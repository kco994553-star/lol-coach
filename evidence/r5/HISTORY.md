# R5 실행 이력

1. 공개 표본 다운로드 초기 시도는 프록시를 모두 끈 환경에서 URLError. 실패 status 원본 보존.
2. 공개 HTTPS만 정상 환경 프록시 허용으로 수정, 로컬 게임 endpoint는 계속 직접 연결. 동일 공식 표본 수신·진단 성공.
3. 공식 인증서 다운로드·파싱 성공. 실제 로컬 game endpoint는 ENDPOINT_UNAVAILABLE. 실제 경기 통과로 기록하지 않음.
4. 별도 검증자가 임시 인증서/가짜 HTTPS 서버로 일치 CA·잘못된 CA·프록시 격리·리디렉트 차단을 검증. 실제 게임 검증과 구분.
5. 공개 YouTube 페이지 확인. 플레이어 재생 시도는 00:00에 머물러 화면 증거 미확보. 공개 자막 export는 성공.
6. 자막 1,230구간→33개 주제 후보. 원문은 재배포하지 않으며 SHA-256·출처·시점 색인·요약만 보존. 화면 미검증/게임시계 미매핑 상태 유지.

기존 R4 실행 이력과 증거는 수정하지 않는다.

7. 플레이어의 실제 VIDEO 요소에 지원 downloadMedia를 실행했으나 60초 시간 초과. 동영상 파일·프레임 확보로 표시하지 않음. 봇 차단으로 분류할 증거는 없음.
