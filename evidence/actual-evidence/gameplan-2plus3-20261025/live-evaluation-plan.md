# GP23-42 실제 경기 평가 계획과 현재 관측

현재 실제 경기·실영상 평가: **UNMEASURED / N=0**. 실제 관측을 입력한 것으로 간주한 합성 fixture나 새 브라우저 검사 결과를 이 표본에 합산하지 않는다. 코드·표현 일관성 검사와 코칭 효과는 서로 다른 평가다.

## 재개 자료와 표본 선정

본인 경기의 허용된 기록/POV와 당시 게임플랜 버전·입력, 정확한 경기 시각 기준점, 해당 시점에 사용자가 알 수 있던 정보를 먼저 확보한다. 개인 계정/경기 식별자·원본은 기존 비공개 경계 안에 둔다. 관전자·사후 결과·현재 영상 재생 시점을 당시의 게임 지식으로 소급하지 않는다. 새로운 게임 클라이언트 계측이나 권한 확장을 이 계획으로 승인하지 않는다.

유리했던 결과만 고르지 않고, 사전에 고정한 연속 경기/구간을 대상으로 정보 누락·실패·중단을 함께 기록한다. 초기 20~30개 적격 장면에서 포지션·교전 문맥·패치·지원 범위를 명시하고, 범위 밖 장면도 제외 이유를 보존한다. 이는 확보 목표이지 현재 확보 수가 아니다.

## 장면별 비교 기준

1. 당시의 정보 상태와 출처·관측 시각이 적절했는가. 최신성 미검증과 stale을 구분한다.
2. 웨이브·자원·기술·지원·퇴로를 고려해 가능한 행동을 선택했는가. 실제로 만들 수 없는 당기기/크래시나 합류를 요구하지 않았는가.
3. 내 목표·위협·위치·행동·중단 조건이 서로 연결됐는가. 탱커의 방해/보호, 원딜 공격 공간, 독립 교전에서의 호응 요구를 따로 검토한다.
4. 대기와 미참여의 손실, 실행 실패 후 회복을 당시 정보로 비교했는가. 결과가 좋았다는 이유만으로 불가능했던 선택을 정당화하지 않는다.
5. 사용자가 실제로 무엇을 이해하고 실행했는가. 계획의 적합성, 화면 이해, 실행 결과를 각기 다른 항목으로 기록한다.

독립 검토자는 원문 계획/입력/당시 정보와 결과를 분리해 평가하고 의견 불일치를 보존한다. 작은 사례 수의 내부 0~2점 평가를 전술 정확도나 승률로 바꾸지 않는다. 실제 비교 기준·적격 N·제외 N·실패 N이 확보되기 전에는 정확도/코칭 효과를 null로 유지한다.

## 이번 실행의 가능한 관측

허용된 실제 경기 원본·POV·시간 기준점이 새로 확보되지 않았다. 따라서 이번 실행에서 관측 가능한 것은 고정 입력의 엔진 출력, 조건 하나 변경 시의 일관성, UI/저장/복귀 동작뿐이다. 그 결과는 GP23-35~41과 별도 영수증에 기록한다. 실제 경기가 없는 사실은 독립 구현·검증·정상 인계를 중단할 이유가 아니다.
