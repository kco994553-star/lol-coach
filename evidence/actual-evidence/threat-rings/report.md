# 위협 범위와 쉬운 교환 설명

## 실제 문장

> 이전: 상대보다 미니언을 먼저 잡을 여유를 늦추지 않는 틈에만…

> 수정: 미니언을 먼저 잡는 흐름을 유지하면서, 상대가 막타를 치러 나오면 사거리 끝에서 짧게 견제한다.

상세 원문: 미니언을 먼저 잡는 흐름을 유지하면서, 상대가 막타를 치러 나오면 사거리 끝에서 짧게 견제한다. 견제 때문에 미니언 잡기가 늦어지면 견제를 멈추고, 남긴 기술로 진입에 대응한다. 중앙 경합에서는 먼저 미니언 처리 우위를 만든 뒤 견제로 공간을 지킨다. 럭스의 광휘의 특이점(E)·케이틀린의 필트오버 피스메이커(Q)가 미니언에도 닿아 의도보다 빨리 밀리는지 본다.

기존 wave.combat에서 요약·상대법·방법이 함께 생성된다. 리스크별 기존 실행 내용은 보존하고, 낮은 자원·상대 기술 소모·교전 시작·포탑 웨이브 등의 별도 분기는 유지했다.

## 두 단계 원의 의미

- 기본값: 실제 선택10명 전원 표시. 1차 실선은 고른 대표 교전 수단; 2차 점선 원은 접근기를 쓰며 위치·자원·반격 위험을 감수하는 조건부 범위. 실제 피해/위험/승리 계산 없음.
- 세주아니: 빙하 감옥(R)1300; 혹한의 맹습(Q)650 + R1300 =1950. 앞 챔피언 충돌·투사체 적중·후속·남은 대응 조건이 필요하다.
- 제드: 죽음의 표식(R)625; 살아있는 그림자(W)650에서 재사용으로 위치 변경 후 R625 =1275. W를 두 번650으로 더하지 않는다. 그림자·재사용·시야·대상·반격 조건이 남는다.
- 10명 프로필: 오른·세주아니·아리·케이틀린·럭스·피오라·리 신·제드·카이사·노틸러스. 다른 챔피언은 회색 BASIC_ONLY 원과 기술 범위 미확인 표시. 전 챔피언의 완성된 기술 위협 지원이라고 세지 않는다.
- 케이틀린·럭스·오른의 검토하지 않은 추가 이동 거리는 만들지 않는다. 케이틀린 E의 투사체750을 반동 거리로 합산하지 않는다. 오른 W25000/Kaisa E1 같은 값을 자동 최대 위협 거리로 택하지 않는다.
- 원은 최대 모든 무기/안전 경계가 아니다. 케이틀린 Q·R, 럭스 R, 제드 Q 등 원 외 추가 원거리 수단은 선택 상세에 별도 표시한다. 원 안을 일괄 확정 피해로 해석하지 않는다.
- 궁극기는1레벨·기술 가용의 가정. 합산 원은 방향·표식/적중/경로/후속이 맞을 때의 상한 참고이며 실시간 유효 범위가 아니다.

## 그림과 조작

원래2000게임단위 가정 좌표를 보존하고, 모든 단계·두 장면의 원을 포함하는 공통 사각형으로 선형 축소했다. 전체 범위 보기에서는 원이 잘리지 않고 배치 확대에서는 원이 화면 밖으로 이어질 수 있다. 실제 지도·거리 측정이나 전투 시뮬레이션 아님.

PC20px/모바일14px 초상화, 지도 위 이름은 숨기고 44px 이상 이름 선택 버튼을 별도 제공한다. 내 원·초상화 금색, 아군 파랑, 상대 빨강. 이름 선택의 펼침·초점을 유지한다. 초상화 선택은 다른 원을 숨기지 않고 강조하며 선택한 챔피언만 보기/원 숨기기는 명시적 선택이다. 단계·확대·동료 연결선은 같은 상태를 공유한다.

## 근거·검토·남은 범위

기존 공식16.20.1 원본의 범위 필드/기전 원문과 URL·패치·SHA·위치를 보존했다. config의 대표 수단 선정, 직접/접근 위험 층 분류와 합산 해석은 별도 설계 가설이며 기존 AUTO/USER 승인 승계가 없다. 원문·지식·보류·영상 이력 변경 없음.

리뷰: 누락 원본의 프로필 파싱 오류, 이름 선택 후 펼침/키보드 초점 손실, 내 원의 색 구분 누락을 재현·수정했다. RED/실패 로그 보존. N=0,30초 이해 미측정,Windows BLOCKED_EXTERNAL. CI/게시/공개 HTTPS·브라우저 결과는 후속 publication 기록에 둔다.
