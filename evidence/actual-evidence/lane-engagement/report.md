# 교전 비교와 웨이브 연결 — 구현 범위

기존 웨이브 우선·Riot ID 대시보드·프로 참고 공개 결과(PR64–66)를 재사용합니다.
새 계약 lane-engagement-v1, additive report.engagement; 기존 입력/기본 선호 호환.
정확한 케이틀린·럭스 대 카이사·노틸러스와 요청한 유나라·룰루 대 루시안·노틸러스만
조건부 비교를 지원합니다. 다른 조합/포지션 배치 미확인/패치 불일치는 미지원입니다.

6구간 선택과 짧은 교환/지속/올인/우리 선진입/받아치기 유형을 연결했습니다.
선택 구간의5유형 비교 표, 소모된 수단 역할·남은 반격·우리 자원·기회 종료/대안·비용,
웨이브 연결과 개별 공식 출처를 제공합니다. 성향과 우세는 독립 필드입니다.
선호/가정은 실제 관측이 아니며 입력 가정과 보수적인 파생 실행 제한을 구분합니다.
주요 상대 적중·보호/자원 부족 등이 있으면 전진 웨이브 실행을 제한하며,
잘못된 추가 가정으로 이미 있는 제한이 풀리지 않습니다. 기존 웨이브 입력은 보존합니다.

## 요청 가설과 현재 판단

사용자 제시 원문 ‘6레벨 이후 유나라·룰루가 거의 확정적으로 이긴다’는
review-queue.json에 USER_PROPOSED_HYPOTHESIS/미채택으로 등록했습니다. USER 결정 행 없음.
현재 자료는 공식 기술 성질이며 이2대2의 교전 피해·적중·자원·처치/이탈 비교나
매칭된 강의/장면 검증이 없습니다. 따라서 모든 구간/유형 우세는 ‘미확인’입니다.
‘경합’으로 대신하지 않고, 승률/확정승리/임의 점수도 만들지 않았습니다.
현재 아군우세/상대우세를 직접 지지해 채택할 근거는 없습니다.

| 비교 가정 | 달라지는 원인·행동 | 판정 한계 |
|---|---|---|
| Lv3~5, 관련 기본기 가용 | 궁극기를 비교에 넣지 않고 기본기·후속·처리 비용을 살핌 | 전체 기본기 습득은 가정; Lv1/2 전체기술 묶음은 불성립 |
| Lv6, 양쪽 주요 수단 가용 | 유나라 자기 초월(R)의 기본기 강화/이동 변화와 룰루 급성장(R)의 체력·주변 제어 추가; 상대 궁극기도 남음 | 보호 성질만으로 상대 제어 무효나 올인 승리 판정 불가 |
| 노틸러스 닻줄 견인(Q) 소모 + 우리 가용 수단/자원·후속·노출·2대2 조건 명시 | 남은 노틸러스 강력한 일격(P)·타이탄의 분노(W)·역조(E), 루시안 이동/연속공격과 궁극기 별도; 싸움 없이 CS 공간 후보 | 기술 하나 소모로 푸시/CS 차단/올인 우세 허가하지 않음 |
| 위 조건 + 성장/주문·우리 선시작·첫 주요 적중 가정 | 처리/이탈 예산을 깨지 않는 짧은 교환 후보; 성향은 후보 강조만 바꿈 | 지속 교전·올인 실행/승리 검증 없음 |
| 우리 보호/자원 부족·동료 단절·적 주요 적중 | 앞으로 나가는 후보 제외; 웨이브 실행 축소, 받을 자원/회복 후보 재비교 | 실제 위치·의도·안전은 관측하지 않음 |
| 우리 선진입 ↔ 상대 선진입 받아치기 | 시작 측을 유형으로 고정하고 첫 접근 비용 ↔ 남은 상대 후속 대응을 구분 | 주요 적중·후속/피해 비교 없이 우세 미판정 |
| 첫 구매/1코어, 레벨 미확인 | 구매만으로6레벨/궁극기 가용을 추정하지 않음 | 레벨 범위·실제 구매/자원 차이 추가 필요 |

‘성장 비슷’은 양 듀오 레벨·구매 아이템 단계 비교이며, 총 획득 골드·보유 골드·정확한
경험치·체력/마나가 같다는 뜻이 아닙니다. 주문·적중·자원은 별도 선택 가정입니다.
CS 공간 비교에 불필요한 성장/주문을 필수로 강요하지 않고, 교환/올인 우열에 필요하지만
없는 정보를 따로 표시합니다. 궁극기 소모는 각각 독립이며 노틸러스 폭뢰(R) 소모가
루시안 빛의 심판(R)을 지우지 않습니다. 스킬 소유자·공식 이름(키), 원문을 보존합니다.
