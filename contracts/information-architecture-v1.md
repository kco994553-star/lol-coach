# LoL Coach 프론트엔드 기능계층 명세 v2.0

- 기준일: 2026-10-25, 한국 시간
- 문서 성격: 이번 대화의 사용자 합의를 반영한 최신 기능계층 및 화면 연결 명세
- 메인 메뉴: **전적 검색 / 챔피언 검색 / 게임플랜 / 경기 중 도우미 / 경기 복기 / 학습실**
- 보조 영역: 작업 상태·지원 정보
- 명세 행: **기존 125개 보존 + 추가·연결 명세 35개 = 160개**. 기존 34개 하위 기능 묶음을 유지하고 챔피언 검색에 6개 묶음을 추가한다.
- 변경 범위: 기능 소속·번호·화면 책임·연결·표시 기준. 이 문서의 작성은 해당 기능의 구현·배포·실경기 검증 완료를 뜻하지 않는다.
- 기능계층 버전과 게임플랜 콘텐츠 버전은 별개다. 기존 게임플랜 콘텐츠 v1.3을 이 문서의 v2.0으로 잘못 바꿔 부르지 않는다.

## 2026-10-25 게임플랜 2+3 보충

게임플랜은 상단 **전체 조합 방향·사용자 기본 방향**과 하단 **라인전·운영·교전 및 한타**로 구성한다. 정글 위치를 고려한 라인관리는 사용자 기본 방향에 포함하고, 교전은 목표·위협·행동·전환을 설명한다. 기존 3.2~3.7 및 160행은 유지하며 신규 구현 완료를 뜻하지 않는다.

상세: [2+3 설계](../docs/gameplan-content/gameplan-2-plus-3-v1.md), [Codex 신규 44개 대기열](../docs/gameplan-content/codex-gameplan-2-plus-3-queue-v1.md).

## 2026-10-25 의미 보정 — 승률 그래프는 파워 그래프

사용자가 말한 ‘승률 그래프’는 **선택 챔피언이 시간대별로 언제 강하고 약한지 파악하는 파워 그래프**를 뜻한다. 이 문서에서 2.3의 기본 화면은 시간대별 파워 그래프이며, 단순 승률 추이 차트나 패치별 통계가 그 목적을 대신하지 않는다.

승률을 곡선의 근거로 사용하면 **승률 기반 파워 경향**으로 표시하고, 강약 구간의 이유와 레벨·아이템·스킬 전환 조건을 함께 설명한다. 특정 상대를 고르면 기준 챔피언 전체의 경향과 그 상대를 만난 경기의 경향을 비교하고 게임플랜으로 연결한다. 기능 번호와 160개 명세 행은 유지한다.

## 개정 이유와 결정

기존 5개 메인 메뉴에 있던 챔피언 탐색을 독립된 **챔피언 검색**으로 추가한다. 사용자는 먼저 챔피언 선택 페이지에서 대상을 고른 뒤 상세로 들어가며, 상세에서는 작은 챔피언 변경 창을 사용한다.

챔피언 검색은 기준 챔피언·포지션의 일반적인 통계와 기본 방향을 보여준다. 상대를 고르면 **그 기준 챔피언이 특정 상대 챔피언을 만난 경기의 최종 게임 승률**, 시간대별 파워 그래프와 비교선, 라인전·운영·한타별 상성 해설을 확인한다. 선택한 정보는 게임플랜 작성 화면으로 전달한다.

예를 들어 기준이 카이사·원딜이고 상대가 직스·원딜이면, 화면 제목과 지표는 **카이사 vs 직스 게임 승률**이다. 설명 없는 ‘상대 승률’이라는 명칭을 사용하지 않는다.

최상위와 두 번째 계층은 안정적인 기능 묶음으로 관리한다. 같은 목적의 추가 기능은 기존 묶음 아래 세 번째 이하 계층에 넣는다. 이번 최상위 개정은 사용자가 지정한 여섯 메뉴를 반영하는 명시적인 버전 변경이다.

## 전체 기능계층

아래 번호는 모두 **v2.0 기준**이다. ‘기존’ 표시는 원래 요구를 보존했다는 뜻이며 구현 완료 상태가 아니다. 세 번째·네 번째 계층은 같은 기능 묶음 안의 기능과 세부 조건이다.

### 2.2 챔피언 개요·통계

기준 챔피언·포지션을 고정해 기본 방향, 전체 통계와 특정 상대 게임 승률을 보여준다.

### 2.3 시간대별 파워 그래프·성장 전환

선택한 챔피언이 시간대별로 언제 강하고 약한지 읽는 파워 그래프를 제공한다. 승률 기반 경향, 특정 상대 비교, 레벨·아이템 전환과 조건 해설을 함께 보여주며 패치별 승률 추이는 보조 통계로 둔다.

| 기능 ID | 기능 | 화면에서 제공할 내용 | 변경 구분 |
|---|---|---|---|
| 2.3.1 | 챔피언의 시간대별 파워 그래프 | 시간대에 따른 기준 챔피언의 강약 경향을 읽는 파워 그래프다. 승률을 곡선 근거로 사용할 때는 ‘승률 기반 파워 경향’과 승률(%) 축을 표시하고 구간별 강약·성장 조건 해설을 함께 제공한다. | 확정 핵심 |
| 2.3.2 | 특정 상대 챔피언 파워 경향 비교 | 같은 집계 조건에서 기준 챔피언 전체의 파워 경향과 ‘기준 챔피언 vs 선택 상대’의 경향을 비교하고 차이가 나타나는 구간의 조건을 설명한다. 두 선 모두 기준 챔피언 관점이다. | 확정 핵심 |
| 2.3.3 | 패치별 승률 추이 | 시간대별 파워 그래프를 기본으로 두고, 보조 통계 탭에서 패치별 승률 추이를 확인한다. 패치별 추이를 시간대별 파워 변화로 표시하지 않는다. | 화면 설계 |
| 2.3.4 | 파워 구간·전환점·상세 근거 | 구간별 파워 경향의 이유, 레벨·아이템·스킬 전환 조건과 상대별 차이를 해설한다. 마우스·터치·키보드로 승률·경기 수·집계 조건도 확인하며, 관측 시각이 없는 전환점은 고정된 분 위치로 그리지 않는다. | 그래프 계약 |
| 2.3.5 | 그래프 자료 부족 상태 | 자료 없음·표본 부족·미지원 조건을 구분한다. 없는 구간은 공백으로 남기고 특정 상대 자료가 없으면 전체 선만 유지한다. | 그래프 계약 |

## 챔피언 통계·그래프의 표시 계약

### 특정 챔피언 대 특정 상대 게임 승률

**정의:** 선택한 챔피언 A·포지션 R이 특정 상대 챔피언 B를 만난 조건 충족 경기 중, A가 속한 팀이 최종 승리한 경기의 비율.

- 기본 목록은 **같은 포지션의 상대**를 비교한다. 예: 카이사·원딜 vs 직스·원딜.
- 상대 팀의 다른 포지션 챔피언을 탐색하는 경우에는 **상대 팀 포함 기준**이라고 별도 표시하고 같은 포지션 통계와 섞지 않는다. 이 범위의 통계가 없으면 해설만 제공할 수 있다.
- 계산은 해당 조건의 승리 경기 수 ÷ 해당 조건의 전체 경기 수 × 100이다.
- 제목·행·그래프 범례에 기준 챔피언을 명시한다. 화면의 ‘승률’이 어느 쪽의 값인지 항상 알 수 있어야 한다.
- 개인 전적의 해당 챔피언 승률은 1.4에 남긴다. 2.2는 명시한 모집단의 공통 통계다.
- 최종 게임 승률을 라인전 승률·솔로킬 확률·운영 점수·한타 점수로 바꾸지 않는다.
- 바텀 서포터 선택이 해설에만 사용되었다면 원딜 상대 통계의 분모는 그대로이며, **2대2 통계로 표시하지 않는다**. 실제로 네 챔피언 조건까지 집계했다면 그 조건과 감소한 경기 수를 표시한다.

|---|---|---|
| 가로축 | 게임 시간 구간 | 초반·중반·후반으로 이어지는 경향을 읽는 기준 |
| 기본 곡선 | 선택 챔피언 전체의 시간별 경향 | 기준 챔피언의 전반적인 파워 경향 |
| 특정 상대 비교선 | 카이사 vs 직스 등 선택 상대 조건의 경향 | 같은 기준 챔피언의 상대별 차이 |
| 세로축 | 실제 사용한 지표와 단위. 승률을 쓰면 승률(%) | 근거 지표를 숨긴 임의 전투력 점수로 바꾸지 않음 |
| 구간 해설 | 강점을 활용할 조건, 버텨야 할 조건, 계획 전환 | 검토된 챔피언·상대 해설과 실제 집계 근거 연결 |
| 성장 전환 | 레벨·스킬·주요 아이템 조건 | 파워 경향이 달라지는 이유와 실행 조건 |
| 상세 근거 | 구간별 승률·경기 수·집계 조건 | 곡선의 자료와 설명 범위 확인 |

- **승률 그래프라고 요청한 기능은 이 파워 그래프를 가리킨다.** 승률 수치만 제시하고 시간대별 강약·성장 조건 해설을 빠뜨리지 않는다.
- 승률을 사용할 경우 그 곡선은 해당 길이 구간에서 끝난 경기의 결과를 집계한 **파워 경향의 참고 지표**다. 예를 들어 25~30분 값은 그 구간에 끝난 경기들의 승률이며, 현재 25분 시점의 승리 확률을 계산한 값은 아니다.
- 강약 해설은 검토된 챔피언 특성·스킬·레벨·아이템·상대 조건을 함께 사용한다. 승률이 올라간 사실만으로 교전 우세의 원인이나 특정 구간의 전투력을 확정하지 않는다.
- 레벨 6·첫 핵심 아이템 같은 전환은 모든 경기에서 같은 분에 발생하지 않는다. 실제 관측된 시각·분포나 사용자가 설정한 가정이 있는 경우에만 시간축에 표시하고, 그 외에는 그래프 아래 조건 카드로 제공한다. 선택 경기의 실제 시점, 여러 경기의 대표 시점, 가정한 시점도 구분한다.
- 구간을 선택하면 **강해지는 이유 → 활용할 행동 → 약해지거나 계획을 바꿀 조건**을 함께 보여준다. 종료 시간별 집계의 자세한 정의는 상세 근거에 두고, 기본 화면에서는 파워 경향과 활용 조건을 먼저 읽게 한다.
- 상대 선택 시 기준 챔피언·포지션·게임 유형·지역·모집단·패치·기간을 유지하고 상대 조건만 바꾼다. 전체 선과 상대 선 모두 기준 챔피언 관점이다.
- 자료가 없는 구간은 선을 끊는다. 특정 상대 곡선이 없으면 제공 가능한 전체 경향과 준비된 해설을 유지하고 부족한 자료를 표시한다.
- 구간을 합칠 때는 승리 수와 경기 수를 각각 합쳐 승률을 다시 계산한다. 임의 곡선 보간이나 근거 없는 0~100 전투력 점수는 사용하지 않는다.
- 구간별 경기 수·조건을 터치와 키보드로도 확인할 수 있게 하고, 색상과 함께 범례·선 모양·텍스트를 사용한다.
- **패치별 승률 추이는 보조 통계**로 별도 탭에 둔다. 시간대별 파워 그래프가 기본이며, 패치 변화와 경기 시간의 흐름을 같은 축으로 섞지 않는다.

### 단계별 상성과 통계의 구분

| 관점 | 주로 설명할 내용 | 필요한 조건 |
|---|---|---|
| 라인전 | 교환 거리, CS 접근, 웨이브, 유지력, 레벨·아이템 전환 | 포지션, 자원·스킬·웨이브, 바텀은 양 팀 서포터 |
| 정글 대결 | 정글링, 침입, 갱킹, 주변 라인 도움, 목표물 준비 | 주변 라인 합류와 확인된 성장·동선 |
| 운영 | 사이드 대면, 웨이브 정리, 압박 후 이동, 합류, 목표물 준비 | 성장, 시야, 아군 위치, 이동 수단 |
| 한타 | 진입·진입 저지, 공격 대상 접근, 앞라인, 보호, 공격 지속 | 전체 조합, 배치, 주요 스킬, 성장 |

상성 카드에는 **판단 태그 → 짧은 이유 → 권장 행동 → 바꿔야 하는 조건**을 기본 표시한다. 같은 상대라도 라인전·운영·한타 판단은 다를 수 있다. 추가 근거·예외·반례는 상세로 확인한다.

## 챔피언 검색 → 게임플랜 연결 계약

| 전달 정보 | 적용 방식 |
|---|---|
| 기준 챔피언·포지션 | 게임플랜의 사용자 챔피언·포지션 초깃값 |
| 선택 상대·확인된 상대 포지션 | 상대 팀의 해당 슬롯에 입력. 다른 포지션 상대를 맞라이너로 자동 지정하지 않음 |
| 아군·상대 서포터 | 바텀 문맥으로 선택했고 슬롯이 확인된 경우 해당 팀에 입력 |
| 통계 패치 | 게임플랜이 사용하는 패치와 비교·표시하고 불일치를 숨기지 않음 |
| 룬·아이템·스킬 문맥 | 입력으로 실제 지원되는 항목과 참고 문맥을 구분 |
| 지역·티어·기간 등 집계 필터 | 통계를 조회한 문맥으로 보존. 이번 경기의 확인된 사실로 자동 적용하지 않음 |
| 검색어·필터·탭·스크롤 위치 | 돌아왔을 때 챔피언 탐색 상태를 복원하는 데 사용 |

1. **「이 챔피언으로 게임플랜」**은 기준 챔피언·포지션을 전달한다.
2. **「이 상대를 넣어 게임플랜」**은 기준 챔피언·포지션·상대와 확인된 서포터 문맥을 전달한다.
3. 챔피언 상세를 보거나 상대를 눌렀다는 이유만으로 저장된 조합을 수정하지 않는다. 연결 버튼에서 적용을 시작한다.
4. 기존 게임플랜을 수정할 때는 관련 슬롯만 반영한다. 중복 챔피언·포지션 충돌·사용자 챔피언 변경을 적용 전에 명확히 표시한다.
5. 남은 픽은 미입력 상태로 보존한다. 기준 챔피언의 일반적인 기본 방향은 볼 수 있지만, 완성 조합이 필요한 분석을 실행한 것처럼 표시하지 않는다.
6. 전체 조합 결과를 다시 계산해야 하는 입력이 바뀌면 이전 결과가 최신 결과인 것처럼 남지 않도록 갱신 상태를 표시한다.
7. 게임플랜 메뉴로 바로 들어가 수동 작성하는 기존 경로도 제공한다.

## 게임플랜의 필수 기본 노출

**화면 순서:** 전체 조합 방향 → 우리·상대 조합 비교표 → 사용자 역할 → 라인전·운영·한타의 행동 요약과 코칭 문단 → 추가 상세.

- 전체 조합은 초반 정글·중반 운영·한타의 방향과 핵심 변수·주요 전장을 설명한다.
- 사용자 계획은 **라인전·운영·한타 각각 핵심 행동 5개**를 기본 표시한다.
- 각 단계는 목록을 읽지 않아도 이해할 수 있는 **독립적인 코칭 문단**을 기본 노출한다.
- 문단은 **왜 이 방향인지 → 구체적으로 무엇을 할지 → 언제 중단하거나 바꿀지**를 연결한다.
- 상세 펼치기는 추가 근거·예외·비교·실행 설명에 사용한다. 기본 방향과 본문을 상세 뒤에 숨기지 않는다.
- 바텀은 양 팀 원딜·서포터의 진입·견제·보호·호응을 함께 설명한다. 지원 정보가 없으면 판단 범위를 표시한다.
- 기다리는 동안 체력·CS·경험치·웨이브·귀환 기회를 잃는 상황도 비용으로 본다. 교전 필요와 교전 가능 조건을 각각 확인한다.
- 조건이 맞으면 기회를 만들고, 조건이 사라지면 웨이브 정리·귀환·정글 도움·합류 변경 등 대안을 제시한다.
- 기본 방향과 이번 조합의 역할 변화, 사용자가 설정한 가정에 따른 실행 변화를 구분한다.
- 요약·문단·상세는 같은 입력과 판단 결과를 사용한다. 화면마다 서로 다른 지시를 만들지 않는다.

## 공통 표시·상태 기준

| 상태 | 화면의 의미와 동작 |
|---|---|
| 조회 중 | 현재 조건을 표시하고 진행 중임을 알림 |
| 제공 가능 | 실제 확보된 자료와 적용 조건을 표시 |
| 자료 없음 | 해당 조건의 기록이 없음을 표시. 0으로 대체하지 않음 |
| 표본 부족 | 수치와 경기 수는 확인 가능하되 경향 판단의 한계를 표시 |
| 해설 준비 중 | 통계 존재와 해설 제공 여부를 별개로 표시 |
| 미지원 조건 | 어떤 조건을 지원하지 않는지와 가능한 대안을 표시 |
| 확인·추정·미확인 | 관측 사실, 근거가 있는 추정, 모르는 정보를 구분 |
| 갱신 지연·패치 불일치 | 마지막 확인 시각과 적용 패치를 표시 |
| 연결 실패 | 원인 범위와 재시도·수동 이용 경로를 표시 |

- 챔피언 목록을 검색할 수 있다는 사실과 모든 상성 해설이 준비되었다는 사실을 분리한다.
- 스킬은 **Q/W/E/R과 공식 기술명**을 함께 표시한다. 영어 용어를 사용하면 **English(한국어 의미)** 형식으로 병기한다.
- 중요한 판단은 색상만으로 전달하지 않는다. 읽을 수 있는 글자 크기, 키보드·터치 조작과 복귀 위치를 유지한다.
- 선택 조건을 바꾸는 동안 이전 요청의 늦은 결과가 새 챔피언·상대의 결과로 표시되지 않게 한다.
- 문서 개정, 구현, 자동 검사, 브라우저 확인, 공개 배포, 실경기 효과 검증은 서로 다른 상태다. 이 문서에서는 진행률을 새로 추정하지 않는다.

## 구현 인수 시 확인할 기준

이 절은 향후 구현을 판단하는 기준이며, 이번 문서 작업에서 제품 기능이 통과했다는 뜻이 아니다.

1. 메인 메뉴가 지정한 6개이며 보조 작업 상태 링크는 별도로 배치된다.
2. 기존 125개 명세 행과 이전 증거의 연결이 유지된다.
3. 계정 검색 없이 챔피언 선택 → 상세 → 게임플랜 작성으로 이동할 수 있다.
4. 챔피언 변경 창의 임시 선택·적용·취소와 돌아가기 상태가 구분된다.
5. 기준 챔피언·포지션이 통계·상대 목록·그래프·상성에서 일치한다.
6. ‘카이사 vs 직스 게임 승률’이 카이사 팀의 최종 승률을 가리키고 분모·조건·경기 수를 확인할 수 있다.
7. 기본 그래프가 시간대별 파워 경향과 성장 전환을 설명하며, 전체 선과 특정 상대 선은 같은 집계 기준을 사용한다. 없는 구간이나 미확인 전환 시각을 채우지 않는다.
8. 바텀 서포터를 해설에만 반영했을 때 2대2 통계가 생긴 것처럼 표시하지 않는다.
9. 라인전·운영·한타 상성은 각각 이유·조건·행동·전환 조건을 포함한다.
10. 게임플랜 이동 시 다른 조합 입력을 보존하고 중복·충돌·미입력을 처리한다.
11. 게임플랜의 비교표, 단계별 행동 5개, 독립 코칭 문단이 기본 노출된다.
12. 지원되지 않는 정보·자료 부족·연결 실패·추정 정보를 사실처럼 표시하지 않는다.
13. 데스크톱과 모바일에서 같은 기능·선택 상태·복귀 경로를 제공한다.
14. 실제 구현·배포·검사 상태는 해당 버전의 증거로 별도 기록한다.
